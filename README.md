# 🌍 Project Polyglot: Custom Language Practice Engine

An automated monorepo workspace containing a high-performance interactive client alongside an extensible multi-language server. Built to easily pull dynamic translation cards based on custom matching language profiles.

Diferent language version of the game "We're Not Really Strangers"

---

## 🚀 Quick Start Guide

This entire workspace was scaffolded instantly using our internal automation pipeline. Follow these instructions to drop straight into runtime:

### 1. Installation & Bootstrapping
If you have just cloned the repo and want to get both layers up simultaneously:
```bash
# Spin up development client engine
cd frontend && npm install && npm run dev

# (In a separate terminal tab) Spin up the server context
cd backend && npm install && npm run dev
